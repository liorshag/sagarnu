# Sagarnu (סגרנו.) — MVP Build Plan (TMDB data, no backend, no database)

A tiny static web app that helps a couple or friends agree on a movie or series fast.
Everyone votes yes / no on a short list, passing **one phone** from hand to hand. Votes stay hidden. The app shows the title everyone said yes to, or the one closest to agreement.

**MVP rules:**
- No server, no database, no accounts.
- Plain **HTML + CSS + JavaScript**. No framework, no build step.
- Movie and series data comes from the **TMDB API**, pulled **once on your computer** by a small script into a static file (`titles.json`). The app itself never calls TMDB, so your API token is never published.
- Default catalog: **what's streaming on Netflix in Israel** (TMDB provider id `8`, region `IL`). Other services can be added with one setting.
- Personal memory (your services, "already seen") lives in the browser (`localStorage`).
- Hosted free as static files (Netlify / GitHub Pages / Vercel).

## 1. What's in / out

### In
- Hebrew UI, right-to-left, mobile-first
- One-phone "pass the phone" mode, 2–6 viewers
- Setup: number of viewers, movie / series, max length, genres (optional), streaming services
- Vote card with TMDB poster, Hebrew title, year, genres, length, short overview, service name
- Votes: **כן, בא לי** / **לא הערב** / **כבר ראיתי**
- Pass-the-phone screen between viewers
- Result: full match or closest to agreement, ranking, and a "where to watch" link
- "Another round" with new titles
- Remembers services and "already seen" titles
- TMDB + JustWatch credit (required)
- Installable to the home screen (optional)

### Out (later, if ever)
- Voting from separate phones (needs a backend)
- Live TMDB calls from the app (see section 4.6 for why not)
- Accounts, history across devices

## 4. Data from TMDB

### 4.1 Get access (10 min)
1. Create a free account at **themoviedb.org**.
2. Settings → **API** → request a key → choose **Developer / personal, non-commercial**.
3. Copy the **API Read Access Token** (the long one, starts with `eyJ…`). That's your `TMDB_TOKEN`.
4. Put it in `tools/.env`:
   ```
   TMDB_TOKEN=eyJhbGciOi...
   ```

### 4.2 TMDB endpoints used

| Purpose | Endpoint | Key parameters |
|---|---|---|
| Movies on Netflix IL | `GET /3/discover/movie` | `watch_region=IL`, `with_watch_providers=8`, `with_watch_monetization_types=flatrate`, `language=he-IL`, `sort_by=popularity.desc`, `vote_count.gte=200`, `page=1…N` |
| Series on Netflix IL | `GET /3/discover/tv` | same |
| Details + providers in one call | `GET /3/movie/{id}` and `GET /3/tv/{id}` | `language=he-IL`, `append_to_response=watch/providers` |
| English overview fallback | same | `language=en-US` (only when Hebrew overview is empty) |
| Genre names in Hebrew | `GET /3/genre/movie/list`, `GET /3/genre/tv/list` | `language=he` |
| Services available in Israel | `GET /3/watch/providers/movie`, `GET /3/watch/providers/tv` | `watch_region=IL`, `language=he-IL` |
| Posters | `https://image.tmdb.org/t/p/w342{poster_path}` | sizes: w185, w342, w500 |

- Base URL: `https://api.themoviedb.org/3`
- Auth header on every request: `Authorization: Bearer <TMDB_TOKEN>`
- `with_watch_providers` accepts several ids: `8|337` = Netflix **or** Disney+. Don't guess other ids — read them from the providers endpoint (the script prints the list).
- Streaming data on TMDB comes from **JustWatch**. It can lag behind Netflix by a few days.

### 4.3 The catalog format (`titles.json`)

```json
{
  "updated": "2026-10-11",
  "region": "IL",
  "providers": [
    { "id": 8, "name": "Netflix", "logo": "https://image.tmdb.org/t/p/w92/....jpg" }
  ],
  "genres": ["אנימציה", "דרמה", "קומדיה", "מתח"],
  "titles": [
    {
      "id": "movie-346648",
      "tmdbId": 346648,
      "type": "movie",
      "title": "פדינגטון 2",
      "original": "Paddington 2",
      "year": 2017,
      "runtime": 103,
      "genres": ["קומדיה", "משפחה"],
      "overview": "…",
      "poster": "https://image.tmdb.org/t/p/w342/....jpg",
      "rating": 7.6,
      "providers": [8],
      "watchLink": "https://www.themoviedb.org/movie/346648-paddington-2/watch?locale=IL"
    }
  ]
}
```
- `type`: `"movie"` or `"series"`. For series, `runtime` = minutes per episode (may be `null`).
- `providers`: TMDB provider ids where the title streams in Israel (subscription only).
- `watchLink`: TMDB's "where to watch" page for Israel (comes from the providers response).

### 4.4 The script: `tools/build-catalog.mjs`

Node 18+ (has `fetch` built in). No packages needed.

```js
// Usage:
//   node --env-file=tools/.env tools/build-catalog.mjs
// Options (env vars):
//   PROVIDERS=8          TMDB provider ids, "|" separated. 8 = Netflix
//   PAGES=5              pages per type (20 titles per page)
//   MIN_VOTES=200        skip obscure titles
import { writeFile } from 'node:fs/promises';

const TOKEN = process.env.TMDB_TOKEN;
if (!TOKEN) { console.error('Missing TMDB_TOKEN in tools/.env'); process.exit(1); }

const REGION = 'IL';
const LANG = 'he-IL';
const PROVIDERS = process.env.PROVIDERS || '8';
const PAGES = Number(process.env.PAGES || 5);
const MIN_VOTES = Number(process.env.MIN_VOTES || 200);
const IMG = 'https://image.tmdb.org/t/p/';

async function api(path, params = {}) {
  const url = new URL('https://api.themoviedb.org/3' + path);
  for (const [k, v] of Object.entries(params)) url.searchParams.set(k, v);
  for (let attempt = 0; attempt < 3; attempt++) {
    const res = await fetch(url, { headers: { Authorization: `Bearer ${TOKEN}`, accept: 'application/json' } });
    if (res.status === 429) { await new Promise(r => setTimeout(r, 1500)); continue; } // rate limited
    if (!res.ok) throw new Error(`${res.status} ${url}`);
    return res.json();
  }
  throw new Error('Too many retries: ' + url);
}

// run tasks a few at a time to stay polite with the API
async function pool(items, size, fn) {
  const out = [];
  for (let i = 0; i < items.length; i += size) {
    out.push(...await Promise.all(items.slice(i, i + size).map(fn)));
  }
  return out;
}

async function genreMap(kind) {
  const { genres } = await api(`/genre/${kind}/list`, { language: 'he' });
  return Object.fromEntries(genres.map(g => [g.id, g.name]));
}

async function discover(kind) {
  const ids = [];
  for (let page = 1; page <= PAGES; page++) {
    const data = await api(`/discover/${kind}`, {
      language: LANG,
      watch_region: REGION,
      with_watch_providers: PROVIDERS,
      with_watch_monetization_types: 'flatrate',
      sort_by: 'popularity.desc',
      'vote_count.gte': MIN_VOTES,
      page
    });
    ids.push(...data.results.map(r => r.id));
    if (page >= data.total_pages) break;
  }
  return [...new Set(ids)];
}

async function details(kind, id, genres) {
  const d = await api(`/${kind}/${id}`, { language: LANG, append_to_response: 'watch/providers' });
  let overview = d.overview;
  if (!overview) overview = (await api(`/${kind}/${id}`, { language: 'en-US' })).overview || '';
  const il = d['watch/providers']?.results?.[REGION];
  const isMovie = kind === 'movie';
  const date = isMovie ? d.release_date : d.first_air_date;
  return {
    id: `${kind}-${id}`,
    tmdbId: id,
    type: isMovie ? 'movie' : 'series',
    title: (isMovie ? d.title : d.name) || (isMovie ? d.original_title : d.original_name),
    original: isMovie ? d.original_title : d.original_name,
    year: date ? Number(date.slice(0, 4)) : null,
    runtime: isMovie ? (d.runtime || null) : (d.episode_run_time?.[0] || null),
    genres: (d.genres || []).map(g => genres[g.id] || g.name),
    overview,
    poster: d.poster_path ? IMG + 'w342' + d.poster_path : null,
    rating: d.vote_average ? Math.round(d.vote_average * 10) / 10 : null,
    providers: (il?.flatrate || []).map(p => p.provider_id),
    watchLink: il?.link || null
  };
}

async function providerList(usedIds) {
  const [m, t] = await Promise.all([
    api('/watch/providers/movie', { watch_region: REGION, language: LANG }),
    api('/watch/providers/tv', { watch_region: REGION, language: LANG })
  ]);
  const all = new Map();
  for (const p of [...m.results, ...t.results]) all.set(p.provider_id, p);
  console.log('\nStreaming services TMDB lists for Israel (id: name):');
  for (const p of all.values()) console.log(`  ${p.provider_id}: ${p.provider_name}`);
  return [...usedIds].map(id => all.get(id)).filter(Boolean).map(p => ({
    id: p.provider_id, name: p.provider_name, logo: p.logo_path ? IMG + 'w92' + p.logo_path : null
  }));
}

const wanted = new Set(PROVIDERS.split('|').map(Number));
const [movieGenres, tvGenres] = await Promise.all([genreMap('movie'), genreMap('tv')]);
const movieIds = await discover('movie');
const tvIds = await discover('tv');
console.log(`Found ${movieIds.length} movies and ${tvIds.length} series. Loading details…`);

const movies = await pool(movieIds, 5, id => details('movie', id, movieGenres));
const series = await pool(tvIds, 5, id => details('tv', id, tvGenres));
// keep only titles that really stream on the chosen services in Israel
const titles = [...movies, ...series].filter(t => t.providers.some(p => wanted.has(p)));
for (const t of titles) t.providers = t.providers.filter(p => wanted.has(p));

const catalog = {
  updated: new Date().toISOString().slice(0, 10),
  region: REGION,
  providers: await providerList(wanted),
  genres: [...new Set(titles.flatMap(t => t.genres))].sort((a, b) => a.localeCompare(b, 'he')),
  titles
};
await writeFile(new URL('../titles.json', import.meta.url), JSON.stringify(catalog));
console.log(`\nSaved ${titles.length} titles to titles.json`);
```

### 4.5 Running it
```bash
# Netflix only (default)
node --env-file=tools/.env tools/build-catalog.mjs

# Netflix + another service (use ids the script printed)
PROVIDERS="8|337" node --env-file=tools/.env tools/build-catalog.mjs

# Bigger catalog
PAGES=10 node --env-file=tools/.env tools/build-catalog.mjs
```
- Default (5 pages × 2 types) ≈ up to 200 titles, about 200–400 API calls, under a minute.
- **Re-run about once a month** and re-deploy, because Netflix's catalog changes.
- `--env-file` needs Node 20.6+. On older Node: `TMDB_TOKEN=xxx node tools/build-catalog.mjs`.

### 4.6 Why not call TMDB directly from the app?
It would work technically, but your token would sit in public JavaScript where anyone can copy it and use your quota. Calling TMDB live without exposing the token needs a small server function, which this MVP avoids on purpose. The monthly script gives the same data with zero risk.

## 6. Logic (`app.js`)

### 6.1 Load the catalog

let catalog;

init();

### 6.2 State
```js
const state = {
  screen: 'home',
  viewers: 2,
  filters: { type: 'movie', maxRuntime: 120, genres: [], providers: [] }, // providers = TMDB ids
  deck: [],        // the 10 titles for this round
  voter: 0,
  idx: 0,
  votes: [],       // votes[voter][idx] = 'yes' | 'no' | 'seen'
  usedIds: []      // titles shown in earlier rounds tonight
};
```

### 6.3 Saved in localStorage
```js
const KEY = 'sagarnu.v1';
// { providers: [8], seen: ['movie-346648', ...], lastFilters: {...} }
function load(){ try { return JSON.parse(localStorage.getItem(KEY)) || {}; } catch { return {}; } }
function save(data){ try { localStorage.setItem(KEY, JSON.stringify(data)); } catch {} }
```

### 6.4 Building the deck
```js
function buildDeck(all, f, seen, used, size = 10){
  const pool = all.filter(t =>
    t.type === f.type &&
    (!f.maxRuntime || t.runtime == null || t.runtime <= f.maxRuntime) &&
    (f.genres.length === 0 || t.genres.some(g => f.genres.includes(g))) &&
    (f.providers.length === 0 || t.providers.some(p => f.providers.includes(p))) &&
    !seen.includes(t.id) && !used.includes(t.id)
  );
  // too few? loosen filters in this order: genres → runtime → providers
  if (pool.length < 6 && f.genres.length)    return buildDeck(all, {...f, genres: []}, seen, used, size);
  if (pool.length < 6 && f.maxRuntime)       return buildDeck(all, {...f, maxRuntime: 0}, seen, used, size);
  if (pool.length < 6 && f.providers.length) return buildDeck(all, {...f, providers: []}, seen, used, size);
  return weightedShuffle(pool).slice(0, size);
}
// popular / well-rated titles come up a bit more often, but still random
function weightedShuffle(a){
  return a.map(t => ({ t, k: Math.random() ** (1 / Math.max(1, t.rating || 5)) }))
          .sort((x, y) => y.k - x.k).map(x => x.t);
}
```
If filters were loosened, show a small note on the first card: "הרחבנו קצת את החיפוש".

### 6.5 Voting
```js
function vote(v){            // v = 'yes' | 'no' | 'seen'
  (state.votes[state.voter] ||= [])[state.idx] = v;
  if (v === 'seen') addSeen(state.deck[state.idx].id);
  state.idx++;
  if (state.idx < state.deck.length) return show('vote');
  state.idx = 0; state.voter++;
  show(state.voter < state.viewers ? 'pass' : 'result');
}
```

### 6.6 Result
```js
function computeResult(deck, votes, viewers){
  const ranked = deck.map((t, i) => {
    const v = votes.map(row => row[i]);
    return { t, i, yes: v.filter(x => x === 'yes').length, seen: v.includes('seen') };
  })
  .filter(r => !r.seen)                       // anyone has seen it → out this round
  .sort((a, b) => b.yes - a.yes || a.i - b.i);
  const top = ranked[0];
  return {
    winner: top && top.yes > 0 ? top : null,
    full: !!top && top.yes === viewers,
    ranked
  };
}
```
- **סיבוב נוסף:** add the deck's ids to `usedIds`, build a new deck, reset votes, go to viewer 1.
- **ראינו את זה:** add the winner to `seen` in localStorage.
- **איפה רואים:** open `winner.t.watchLink` in a new tab (TMDB's watch page links on to Netflix).

### 6.7 Small details that matter
- The pass screen must fully cover the vote screen (no peeking at the last vote).
- Disable the vote buttons for ~250ms after each tap (no double votes).
- Posters: `loading="lazy"`, set `width`/`height` to avoid layout jumps, and preload the next card's poster: `new Image().src = next.poster`.
- Render titles and overviews with `textContent`, not `innerHTML`.
- Overview: clamp to 3 lines with CSS (`-webkit-line-clamp: 3`).
- If `titles.json` fails to load, show "לא הצלחנו לטעון את רשימת הסרטים" + retry button.

## 7. Build steps

### Step 1 — Set up (30 min)
1. Install **Node.js 20+** and **VS Code** with the **Live Server** extension (or run `npx serve .`).
2. Create the folder and files from section 2. Add `.gitignore`.
3. `index.html`: `<html lang="he" dir="rtl">`, Google Fonts link, `style.css`, `app.js` with `defer`.
4. Open with Live Server. A plain dark page = success.

> `fetch('titles.json')` doesn't work if you double-click the file (`file://`). Always use a local server.

### Step 2 — Get the TMDB data (30 min)
1. Get your token (4.1) and put it in `tools/.env`.
2. Paste the script from 4.4 into `tools/build-catalog.mjs`.
3. Run `node --env-file=tools/.env tools/build-catalog.mjs`.
4. Open `titles.json` and check: Hebrew titles, posters, `"providers": [8]`.
5. Note the provider list the script printed in case you want to add services later.

### Step 3 — Styles and screens (½ day)
1. Put the tokens from section 3 in `style.css`.
2. Write all 5 `<section>`s in `index.html` with static content first.
3. `.screen{display:none}` `.screen.active{display:flex}`.
4. Check at 360px and 430px width (browser dev tools → phone mode).

### Step 4 — Logic (½–1 day)
1. Load the catalog (6.1), build Setup chips from it.
2. Implement `show(screen)`, `buildDeck`, `vote`, `computeResult` (section 6).
3. Render the vote card and the result from state.
4. Save services and seen titles to localStorage.
5. Add the TMDB attribution (4.7).

### Step 5 — Test (1–2 hours)
On a real phone:
- 2 viewers both say yes to the same title → "סגרנו! כולם אמרו כן"
- 3 viewers, best is 2/3 → "הכי קרוב להסכמה: 2 מתוך 3"
- Everyone says no → "אף אחד לא אמר כן." and a new round works
- "כבר ראיתי" removes the title from the result and from later rounds
- Very narrow filters → the deck still has titles
- Reload → services still selected
- "איפה רואים" opens the right title
- A title with no Hebrew overview shows the English one

### Step 6 — Publish (30 min)
**Never upload `tools/.env`.** Only these go online: `index.html`, `style.css`, `app.js`, `titles.json`, icons, `manifest.json`, `tmdb-logo.svg`.
- **Netlify Drop:** app.netlify.com/drop → drag a folder that contains only the files above.
- **GitHub Pages:** push the repo (with `.gitignore` in place) → Settings → Pages → deploy from `main`.
- **Vercel:** import the repo, framework "Other", no build command.

Open the link on your phone → Share → **Add to Home Screen**.

### Step 7 — Monthly refresh (5 min)
Re-run the script, check `titles.json`, re-deploy.

### Step 8 — Optional: install as an app
`manifest.json`: name "סגרנו.", `"lang": "he"`, `"dir": "rtl"`, `"display": "standalone"`, `"background_color": "#12131c"`, `"theme_color": "#12131c"`, two icons. Link it in `<head>`.
